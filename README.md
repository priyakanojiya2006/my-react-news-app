# React Movie Search App

A responsive movie search app built with React.js that fetches live data from a public movie API.

## Features
- Click the search icon (top right) to reveal the search bar
- Search movies by title
- Filter results
- View movie details with conditional rendering
- Loading and error states for failed API calls

## Tech Stack
React.js, JavaScript (ES6+), REST API, CSS
